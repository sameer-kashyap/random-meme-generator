# 😂 Meme Generator (API Based)

This project is a **simple Meme Generator web app** built using **HTML, CSS, and JavaScript**.  
On every click, the application fetches and displays a **new random meme** using an external API.

The project was created to practice **API integration**, asynchronous JavaScript, and dynamic content rendering.

---

## 🚀 Project Overview

The Meme Generator allows users to:
- Generate a new meme with a single click
- Fetch meme data dynamically from an API
- View memes instantly without refreshing the page

This project introduces basic backend interaction through API usage.

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & layout
- **JavaScript (Vanilla JS)** – Logic & API handling
- **REST API** – Fetching random memes

---

## ✨ Features

- Random meme generation
- API-based data fetching
- Dynamic image updates
- Simple and clean UI
- Fast and lightweight
